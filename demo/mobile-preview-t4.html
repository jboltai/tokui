T4 移动端改造 · 前后对照预览

左侧为现状：用当前发布版 /lib/tokui.umd.js 在 375px 视口内真实渲染的 DSL；右侧为 T4.1 / T4.2 提案效果的手工示意（纯 HTML/CSS，未改任何框架代码）。两支手机框内均可上下滚动体验。

一、表格移动卡片化 table v:cards（T4.2）

同一份工单表数据：现状在 375px 下被压成密排小字 + 横向滚动；改造后窄容器（<640 容器查询命中）行转卡片，label 取表头、每行一卡纵向铺开。

  • 触发条件：容器查询 < 640px 自动切换（宽容器仍是表格，同一份 DSL）。
  • 卡片头部 = 行首关键列（工单号 + 优先级 tag）；中部 label:value 网格，label 直接取 thead 表头，数据不丢列。
  • 操作列收进卡片底部（查看 / 编辑），不再挤占横向空间。

二、导航壳 nav-bar + tabbar（T4.1）

现状用 page-header（面包屑+动作区）与 tabs 在 375px 下的真实表现；改造后顶部 nav-bar（返回+标题+动作）、底部 tabbar（图标+角标），斜纹条示意 env(safe-area-inset-*) 安全区。

  • nav-bar：sticky 顶 + back:clk:goBack 返回键 + 右侧动作插槽；顶部斜纹 = env(safe-area-inset-top) 安全区垫高。
  • tabbar：fixed 底部 + env(safe-area-inset-bottom)；act 激活切换 + change 事件；角标 badge:3 复用既有 badge 体系。
  • 安全区由组件内部处理，宿主无需操心 iPhone 刘海/小白条。
nav-bar 返回键 → aria-label="返回"（i18n 可配） tabbar → role="navigation" + aria-label="主导航" 激活项 → aria-current="page" badge:3 → aria-label="3 条未读"
